## Project title

Knee MRI AI: PyTorch Training, Inference & Evaluation

## Your role

Machine Learning Engineer — Computer Vision & Research Pipelines

## Project description

Built a knee MRI research pipeline for 12 findings using PyTorch. Developed series-aware DICOM preprocessing, CoAtNet/ResNet fusion experiments, attention-MIL pooling, resumable GPU training, EMA, and inference validation. Audited results with paired bootstrap intervals, calibration plots, and checkpoint checks. The validation-selected EMA model recorded 0.9251 macro ROC-AUC on 74 studies; its gain over the parent remains uncertain. Includes tested code, technical docs, and credited public baselines.
